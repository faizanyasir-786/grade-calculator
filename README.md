# Grade Calculator

A simple Python program that calculates a student's total marks, percentage, grade and pass/fail result from subject marks entered by the user.

## Features

- Takes the marks for any number of subjects
- Validates input (marks must be a number between 0 and 100)
- Calculates the total marks and percentage
- Assigns a grade (A, B, C, D or F) based on the percentage
- Prints a clear report card with the final result

## Grading Scale

| Percentage | Grade |
|------------|-------|
| 90 and above | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| Below 60 | F |

## How to Run

1. Install [Python 3](https://www.python.org/downloads/).
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

```
python grade_calculator.py
```
